# Mythirium

> a multidimensional portfolio artifact, four faces, four fragments, one tiny universe.

**Mythirium** is an interactive 3D portfolio cube built as a strange little entrance into my work and world.

It floats, rotates, pauses beneath your cursor, and unfolds whenever you select a face. Each side preserves a different fragment of its creator: identity, toolkit, archive, and connections.

## the four faces

* **xaynakive** — the human behind the artifact
* **toolkit** — technologies, disciplines, and creative weapons
* **archive** — selected projects and things brought to life
* **links** — doors leading elsewhere on the internet

## interactions

* continuously rotating 3D cube
* hover to pause and inspect
* golden-hour glow across each face
* clickable polaroid surfaces
* faces that expand into glassy information drawers
* smooth opening, closing, and return animations
* responsive mouse and touch interactions

## built with

* HTML
* CSS
* vanilla JavaScript
* CSS 3D transforms
* an unreasonable amount of atmosphere

No frameworks. No libraries. Just a tiny universe made by hand.

## origin

It was originally called **GlamosCube** — a rotating experiment built for the hero section of my portfolio. ([Lovable Version →](https://glamoscube.lovable.app/))

But it became something stranger than a decorative cube. Every surface turned into a portal, and every portal revealed another fragment of me.

So it needed a name of its own.

**Mythirium** combines the feeling of myth, ether, and an undiscovered element: something imagined, atmospheric, and capable of containing an entire world.
